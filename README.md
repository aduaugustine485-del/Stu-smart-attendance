### [Stu Smart Attendance](https://github.com/aduaugustine485-del/Stu-smart-attendance)

A responsive, single-page attendance dashboard concept designed to make classroom attendance information easy to scan. It presents sample attendance statistics, student records, and attendance statuses in one place.

**Built with:** HTML · CSS

**Highlights**

- Dashboard layout with attendance and class metrics
- Student attendance table with present, late, and absent states
- Responsive styling for smaller screens
- No build step or external dependencies required

> This repository currently contains a static front-end prototype. The displayed names and attendance figures are sample content; the dashboard is not connected to a live attendance system.
